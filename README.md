## 📖 简介

**CogniAND** 是一个面向认知科学、心理学与神经科学研究的在线平台,把**实验参与、量表评估、认知训练、科研资讯与数据采集**整合在一个网站里。无论是研究者发布实验、被试在线参与,还是临床/教学场景下的认知评估,都可以在浏览器中直接完成,无需安装。

## ✨ 主要功能

| 模块 | 说明 |
|---|---|
| 🧪 **在线实验** | 丰富的心理学 / 认知科学实验,浏览器直接参与;支持访客试玩,登录后可记录参与与评分 |
| 📰 **学术前沿** | 精选认知 / 神经科学领域的研究资讯与文摘 |
| 🧠 **SCTC** | 社会认知评估与训练系统 —— 问卷量表、社会认知训练与多任务评估,生成综合报告 |
| 🏥 **CARE** | 临床认知评估与随访系统 —— 面向医师与被试协同的任务派发、随访追踪与评估记录 |
| 🔗 **ANDFLOW** | 可视化 AI 工作流编排平台 —— 拖拽式搭建智能体与自动化流程 |
| 📡 **生理信号采集** | 实验中可选接入脑电(EEG)/ 眼动采集,支持事件打点,用于科研数据收集 |
| 📚 **资源中心** | 使用文档与帮助中心、桌面客户端、医疗文档 OCR 等配套工具 |

## 🚀 快速开始

1. 打开 **[cogniand.com](https://cogniand.com)**。
2. 在首页浏览**实验列表**或**学术前沿**;点击任意实验即可查看介绍。
3. **参与实验**:访客可直接试玩;**注册 / 登录**后,参与记录、评分与个人数据会被保存。
4. 通过顶部导航的 **「平台」** 进入各子系统:**SCTC**(社会认知评估训练)、**CARE**(临床认知评估)、**ANDFLOW**(AI 工作流)。
5. 在 **「资源」** 中查看使用文档、下载桌面客户端等。

> 💡 部分实验支持脑电 / 眼动采集,需配合相应采集设备与客户端,主要面向科研场景。

## 👥 适用人群

- **研究者 / 实验员** —— 发布与管理在线实验,收集参与数据。

- **临床 / 教学** —— 通过 CARE 进行认知评估与随访。
- **对认知科学感兴趣的访客** —— 浏览学术前沿,试玩公开实验。
