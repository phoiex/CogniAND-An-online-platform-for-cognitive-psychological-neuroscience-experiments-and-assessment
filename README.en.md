## 📖 Overview

**CogniAND** is an online platform for cognitive science, psychology and neuroscience research. It brings **experiment participation, scale-based assessment, cognitive training, research highlights and data collection** together in a single website. Whether you are a researcher publishing experiments, a participant joining online, or running assessments in a clinical/teaching setting, everything runs in the browser — no installation required.

## ✨ Key Features

| Module | What it does |
|---|---|
| 🧪 **Online Experiments** | A growing library of psychology / cognitive-science experiments, run right in the browser; guests can try them, and signing in records participation and ratings |
| 📰 **Research Highlights** | Curated news and digests from cognitive / neuroscience research |
| 🧠 **SCTC** | Social Cognition assessment & training — questionnaires, social-cognition training and multi-task assessment with a comprehensive report |
| 🏥 **CARE** | Clinical cognitive assessment & follow-up — clinician–participant collaboration with task dispatch, follow-up tracking and assessment records |
| 🔗 **ANDFLOW** | A visual AI workflow orchestration platform — build agents and automations by drag-and-drop |
| 📡 **Physiological Signals** | Optional EEG / eye-tracking acquisition during experiments, with event markers, for research data collection |
| 📚 **Resources** | Docs & help center, desktop client, medical-document OCR and other companion tools |

## 🚀 Quick Start

1. Open **[cogniand.com](https://cogniand.com)**.
2. Browse the **experiment list** or **research highlights** on the home page; click any experiment to read its description.
3. **Join an experiment**: guests can try it directly; after **signing up / logging in**, your participation, ratings and personal data are saved.
4. Use the **"Platform"** menu in the top navigation to enter the sub-systems: **SCTC** (social-cognition assessment & training), **CARE** (clinical cognitive assessment), **ANDFLOW** (AI workflows).
5. Find user docs, the desktop client and more under **"Resources"**.

> 💡 Some experiments support EEG / eye-tracking acquisition, which requires the corresponding devices and client — primarily for research scenarios.
